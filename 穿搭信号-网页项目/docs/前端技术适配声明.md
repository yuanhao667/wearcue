# 穿搭信号前端技术适配声明

## 目标

以 `mvp.html` 为产品结构与交互参考，在现有 Next.js 16 工程中实现可上线的移动端 Web MVP。参考页只提供信息层级与交互路径，不复制其中的登录、模拟数据、CDN 图标或动画实现。

## 当前适配

- 前端：Next.js 16、React 19、TypeScript 严格模式、原生 CSS。
- 后端：统一通过 `/api/backend/*` 同源代理访问 FastAPI `/api/v1/*`，浏览器不直接依赖后端域名。
- 数据：天气、推荐、设置、灵感上传和衣橱均以后端为唯一业务数据源。
- 素材：继续使用已经验收的本地 SVG 服装图标，不引入第二套素材。
- 视觉：采用亮色潮流电商工具语言，使用冷白画布、黑白高对比、轻量卡片、现代无衬线字体和克制的荧光绿信号；页面结构和交互继续以 `mvp.html` 为准。
- 运行环境：本地默认连接 `http://127.0.0.1:8000`；上线时通过 `BACKEND_URL` 指向云端后端。

## MVP 边界

- 不实现微信登录。
- 不实现自定义场景，只保留通勤、约会、出行。
- 图片识别默认走后端安全 Mock 工作流；只有后端配置生产视觉模型并明确允许后才会传给第三方。
- 推送保留设置入口，但生产推送依赖后端 VAPID 配置。
