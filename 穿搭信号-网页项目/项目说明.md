# 穿搭信号 · 网页项目交付说明

Slogan：每天少想一件事：穿什么。

这是截至 2026-08-24 的当前可运行网页项目备份，已覆盖为本地正在预览的最新版。包含首页、衣橱/灵感库、图片上传与分析、每日推荐、设置、图标实验页、天气接口、推荐逻辑、响应式布局和测试。

## 如何运行

先安装 Node.js 和 pnpm，然后在当前文件夹打开终端：

```bash
pnpm install
pnpm dev
```

浏览器打开：<http://localhost:3456>

正式运行构建版本：

```bash
pnpm build
pnpm start
```

## 文件说明

- `src/`：网页页面、组件、推荐逻辑和接口代码
- `public/`：衣物图标等静态资源
- `package.json`：项目依赖和运行命令
- `.env.example`：天气服务环境变量示例
- `穿衣助手_MVP_SPEC.md`：当前产品与技术 Spec
- `打开项目.html`：可双击查看的入口说明页

## 需要注意

`打开项目.html` 是项目入口说明，不是功能完整的离线静态版。天气查询和设置等功能需要项目服务运行。此交付目录刻意没有复制体积很大的 `node_modules/` 和 `.next/` 缓存；首次运行时使用 `pnpm install` 安装依赖即可。
